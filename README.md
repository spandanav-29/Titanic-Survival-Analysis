# Titanic Survival Analysis

## Project Overview
This project analyzes Titanic passenger survival data using PostgreSQL, Python, and Streamlit.

## Technologies Used
- Python
- PostgreSQL
- Pandas
- Streamlit
- Plotly

## Features
- Passenger data analysis
- Overall survival percentage
- Gender-wise survival analysis
- Passenger class analysis
- Age-group analysis
- Embarkation analysis
- Interactive charts and filters

## Dataset
The project uses the Titanic passenger dataset containing 891 records.

## Key Findings
- Total passengers: 891
- Survivors: 342
- Non-survivors: 549
- Overall survival rate: 38.38%
- Female survival rate: 74.20%
- Male survival rate: 18.89%

## How to Run
1. Install dependencies:
   pip install -r requirements.txt
2. Configure PostgreSQL credentials in .streamlit/secrets.toml.
3. Run:
   streamlit run app.py
